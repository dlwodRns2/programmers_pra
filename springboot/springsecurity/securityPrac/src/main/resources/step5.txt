문제점 확인 : 처음 브라우저가 팝업을 띄우고 id/pw를 입력한 시점에 브라우저가
Authorization : Basic 인코딩 값을 브라우저 프로세스 내의 인메모리 HTTP 인증 캐시에 저장
=> 1. 탭을 닫고 다시 localhost:8080/hello로 이동 : 브라우저 프로세스는 여전히 살아있음
=> 2. 서버 재시작 : 브라우저가 값을 들고 있으므로 서버 재시작은 의미가 없음
=> 해결법1 : 브라우저를 종료하고 다시 켠다. 브라우저 프로세스를 종료하고 재시작하여 캐시를 초기화
=> 해결법2 : 시크릿 창을 사용한다. 일반 브라우저는 프로필 단위로 쿠키/localStorage/Http 인증 캐시를 저장.
시크릿 탭은 프로필과 완전히 분리된 독립적인 임시 세션을 만듦.
